## Возможности

### 🎵 Воспроизведение аудио

- **Многоформатность**: MP3 / WAV / OGG / M4A / FLAC / AAC
- **Управление воспроизведением**: воспроизведение / пауза, предыдущий / следующий трек
- **Прогресс и время**: полоса прогресса и отображение текущей / общей длительности
- **Скорость воспроизведения**: регулируется от 0,5× до 2,0×
- **Громкость**: без звука, 25 %, 50 %, 75 %, 100 %
- **Очередь воспроизведения**: просмотр текущей очереди и быстрый переход между треками

### 🎛️ Режимы воспроизведения

- **Последовательно**: по порядку списка, остановка в конце списка
- **Повтор списка**: после конца списка воспроизведение начинается сначала
- **Повтор трека**: многократное воспроизведение текущего трека
- **Перемешивание**: треки воспроизводятся в случайном порядке

### 📚 Управление музыкальной библиотекой

- **Все треки**: все найденные музыкальные файлы
- **Избранное**: добавление в избранное в одно касание для быстрого доступа
- **Плейлисты**: создание / редактирование / удаление собственных плейлистов
- **Исполнители**: треки, сгруппированные по исполнителю
- **Альбомы**: треки, сгруппированные по альбому
- **Поиск**: поиск треков, исполнителей и альбомов

### 🎤 Тексты песен

- **Источник**: тексты песен считываются **только из встроенных метаданных аудиофайлов**. Плагин не читает внешние файлы с текстами на диске и не загружает тексты через интернет.
  - **Обычные тексты**: стандартные тексты в формате LRC в тегах
  - **Пословные тексты**: тексты с метками времени для каждого слога / слова (в стиле караоке)
- **Отображение**:
  - **Три строки**: предыдущая, текущая и следующая строки
  - **Полноэкранные тексты**: полный список с автоматической прокруткой и подсветкой
- **Синхронизация**: тексты автоматически следуют за позицией воспроизведения

> Подробнее о форматах текстов песен см. раздел «[Формат текстов песен](#формат-текстов-песен)» ниже.

### 🎨 Интерфейс и взаимодействие

- **Обложки альбомов**: встроенные обложки или изображения в папке трека с необязательной анимацией вращения диска
  - Порядок поиска обложки:
    1. Файл изображения с именем `cover` в той же папке, что и трек (например, `cover.jpg`, `cover.png`, без учёта регистра)
    2. Изображение в той же папке с тем же именем, что и трек (например, `song.mp3` → `song.jpg`)
    3. Встроенная обложка из метаданных аудиофайла
- **Анимация переключения диска**: при использовании кнопок «предыдущий / следующий» или горячих клавиш диск показывает анимацию перехода
- **Вид диска**: полноэкранный интерфейс воспроизведения в стиле диска
- **Вид текстов песен**: экран, сфокусированный на тексте песни
- **Адаптивная вёрстка**: работает на компьютере и на мобильных устройствах
- **Горячие клавиши**: см. раздел «[Горячие клавиши](#горячие-клавиши)» ниже

### ⚙️ Настройки

- **Папка с музыкой**:
  - поиск и выбор папки с музыкой;
  - нажмите на поле ввода, чтобы открыть список папок;
  - если оставить поле пустым, сканируется всё хранилище (для больших хранилищ рекомендуется выделить отдельную папку для музыки).
- **Автовоспроизведение при открытии**: воспроизводить ли первый трек при открытии плеера
- **Режим воспроизведения по умолчанию**: начальный режим настраивается в параметрах

### 🔄 Автосинхронизация и индексация

- **Отслеживание файлов**: отслеживает создание, удаление, переименование и перемещение музыкальных файлов
- **Обновление библиотеки**: обновляет данные библиотеки при перемещении файлов в папку с музыкой и из неё
- **Проверка согласованности**: при запуске проверяет соответствие индекса и файловой системы
- **Подсказка о перестроении**:
  - когда рекомендуется перестроить индекс, на кнопке перестроения появляется маленькая точка;
  - перестроить индекс можно вручную, нажав на кнопку.

## Установка

### 📦 Ручная установка

Для **локальных сборок для разработки** или если плагин ещё не добавлен в каталог сообщества:

1. Перейдите на страницу [Releases](https://github.com/TracingOrigins/obsidian-music-player-plugin/releases) и скачайте последний архив или файлы плагина.
2. Распакуйте / поместите папку плагина в каталог плагинов Obsidian (обычно:
   - `<Ваше хранилище>/.obsidian/plugins/music-player/`).
3. В Obsidian откройте **Настройки → Сообщество плагинов → Установленные плагины** и включите этот плагин.

### 🔧 Установка через BRAT (рекомендуется тестировщикам)

Для **бета-версий / последних сборок для разработки**:

1. Установите плагин [BRAT](https://github.com/TfTHacker/obsidian42-brat).
2. В настройках BRAT выберите **Add beta plugin** («Добавить бета-плагин»).
3. Введите репозиторий: `TracingOrigins/obsidian-music-player-plugin`.
4. После установки включите плагин в разделе **Настройки → Сообщество плагинов → Установленные плагины**.

## Использование

### Быстрый старт

1. Включите плагин (**Настройки → Сообщество плагинов → Установленные плагины**).
2. Нажмите на значок музыки на левой панели или запустите команду **Открыть музыкальный плеер** через палитру команд.
3. При первом использовании рекомендуется указать в настройках плагина **отдельную папку для музыки**:
   - можно оставить поле пустым — тогда будут сканироваться аудиофайлы во всём хранилище.
4. Нажмите на любой трек в списке, чтобы начать воспроизведение.

### Формат текстов песен

Плагин считывает следующие форматы текстов из **встроенных тегов** аудиофайлов:

> **Примечание:** плагин **не** читает отдельные файлы `.lrc` рядом с треками и **не** загружает тексты через интернет; обрабатываются только встроенные теги с текстами песен.

- **Обычные тексты (в стиле LRC)**
  Пример:
  ```text
  [02:22.94]外婆她的期待
  [02:26.14]慢慢变成无奈
  [02:29.08]大人们始终不明白
  [02:34.97]她要的是陪伴
  [02:37.97]而不是六百块
  [02:40.96]比你给的还简单
  ```
- **Пословные тексты (в стиле караоке)**
  В пословных текстах после **метки времени начала строки** каждый символ или слово обрамляется тегом `<время>`. Пример:
  ```text
  [02:23.43]<02:23.43>外<02:23.65>婆<02:23.83>她<02:24.18>的<02:24.71>期<02:24.90>待<02:25.63>
  [02:26.00]<02:26.00>慢<02:26.28>慢<02:26.68>变<02:27.02>成<02:27.40>无<02:27.83>奈<02:28.68>
  [02:29.00]<02:29.00>大<02:29.30>人<02:29.69>们<02:30.03>始<02:30.28>终<02:30.61>不<02:30.83>明<02:31.18>白<02:34.00>
  [02:34.96]<02:34.96>她<02:35.25>要<02:35.65>的<02:36.02>是<02:36.34>陪<02:36.77>伴<02:37.62>
  [02:37.93]<02:37.93>而<02:38.22>不<02:38.53>是<02:38.88>六<02:39.19>百<02:39.63>块<02:40.61>
  [02:40.94]<02:40.94>比<02:41.21>你<02:41.55>给<02:41.96>的<02:42.31>还<02:42.68>简<02:43.03>单<02:44.84>
  ```

### Очередь воспроизведения

Нажмите кнопку **очереди / плейлиста** в нижней панели управления, чтобы:

- просмотреть все треки в текущей очереди;
- выполнить поиск внутри очереди;
- нажать на любую строку для переключения воспроизведения;
- увидеть обложку, название, исполнителя и альбом каждого трека;
- увидеть подсветку текущего воспроизводимого трека.

### Горячие клавиши

Когда вид музыкального плеера находится в фокусе:

- **Пробел**: воспроизведение / пауза
- **↑**: предыдущий трек
- **↓**: следующий трек
- **←**: перемотка назад на 5 секунд
- **→**: перемотка вперёд на 5 секунд
- **Ctrl + ←**: перемотка назад на 15 секунд
- **Ctrl + →**: перемотка вперёд на 15 секунд

(Точные сочетания клавиш могут соответствовать настройкам Obsidian; в будущих версиях горячие клавиши могут быть добавлены или изменены.)

## Частые вопросы

#### В: Что означает маленькая точка на кнопке перестроения индекса?

**О:** Индекс может быть не синхронизирован с файловой системой; рекомендуется перестроить индекс вручную. Частые причины:

- музыкальные файлы удалены вне Obsidian (например, через Проводник);
- файлы перемещены или переименованы без обновления индекса;
- данные индекса повреждены или неполные.

**Что делать:**

1. Нажмите **Перестроить индекс** (с точкой) для перестроения;
2. после завершения перестроения точка исчезнет.

**Примечание:** даже без перестроения список библиотеки отражает состояние файловой системы в реальном времени (удалённые файлы исчезают из списка). Перестроение в основном очищает устаревшие записи индекса и обновляет метаданные.

## Разработка

- Клонируйте репозиторий:
  - `git clone https://github.com/TracingOrigins/obsidian-music-player-plugin.git`
- Node.js **v16+** (рекомендуется актуальная LTS-версия):
  - `node --version`
- Установите зависимости:
  - `npm install`
- Разработка (рекомендуется):
  - `npm run dev`
  - Выполняет `node scripts/deploy.mjs dev`, создаёт символическую ссылку на `dist` в вашем хранилище и запускает сборщик в режиме отслеживания изменений для локальной разработки.
- Сборка и развёртывание в тестовое хранилище:
  - `npm run build`
  - Выполняет проверку типов TypeScript и производственную сборку, затем `node scripts/deploy.mjs build` копирует результаты из `dist` в папку плагина хранилища для тестирования или выпуска.

> Скрипт развёртывания читает файл `.env` в корне проекта. Укажите:  
> `VAULT_PATH=/path/to/your/Obsidian/vault`.  
> Идентификатор плагина берётся из `manifest.json`; файлы оказываются в `<VAULT_PATH>/.obsidian/plugins/<pluginId>/`.
